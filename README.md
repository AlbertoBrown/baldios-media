# Baldíos Media

Aplicación web/PWA para organizar y subir fotografías de **Combustibles Los Baldíos** directamente desde el móvil.

## Secciones iniciales
- Sonda Veeder
- Proconsi
- Camiones
- Otros

Las fotografías se guardan en `media/<seccion>/AAAA/MM/`.

> Importante: el repositorio es actualmente **público**, por lo que las fotografías subidas también serán públicas.

La app usa la API de GitHub desde el navegador. Para subir fotos necesita un token Fine-grained de GitHub con permiso **Contents: Read and write** limitado a este repositorio.
